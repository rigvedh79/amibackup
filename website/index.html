AWS Static Website Hosting Project

Static Website Hosted on Amazon S3

This website demonstrates static website deployment using Amazon S3, public access configuration, bucket policies, and AWS cloud storage.

Deployed on Amazon Web Services

Project Highlights

Amazon S3

Stores and serves static website files such as HTML, CSS, and images.

Static Website Hosting

Configured the S3 bucket to serve index and error documents.

Bucket Policy

Applied controlled public read access for website objects.

Cloud Deployment

Deployed and tested the website using the Amazon S3 website endpoint.
